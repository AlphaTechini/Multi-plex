# 13 · Capability checks

Before building on a feature of a platform, library or agent CLI that we are not sure works as claimed, we prove it with a small script. Each check lives in `capability-checks/<id>-<name>/` with a `README.md` (what it tests, how to run, result) and the code. If a check needs credentials, add a `.env.example` and never commit `.env`.

**Run Windows first.** It is the main development platform and the hardest one.

| ID | Question | How | Pass when | Blocks |
|---|---|---|---|---|
| CC-01 | Can we host agent CLIs in ConPTY from Go? | Spawn `pwsh` and `claude` through `xpty`, write input, read output, resize, wait for exit with xpty's wait helper | Interactive use works, resize reflows, exit code is correct | Phase 1 |
| CC-02 | Which VT emulator renders agent TUIs correctly? | Feed recorded PTY streams of Claude Code, opencode, vim and btop through each candidate and compare with Windows Terminal | No visible glitches in colours, cursor, wide characters or scrolling | Phase 1 |
| CC-03 | Does libghostty-vt build and link through cgo on all three OSes? | Minimal Go program calling the C API, built on Windows, macOS, Linux | Release build works on all three; document the toolchain | Phase 1 (if chosen) |
| CC-04 | Does Bubble Tea v2 meet our UI needs in our target terminals? | Test truecolor, mouse clicks, Shift+drag native selection, keyboard enhancements in each terminal from [06](06-ui-layout.md) | Works, or the limits are documented with workarounds | Phase 1 |
| CC-05 | Can a console app trigger Windows Hello reliably? | C++/WinRT helper calling `UserConsentVerifier`, launched from a terminal | Prompt appears in front; success, cancel, timeout and "not available" are distinguishable; latency recorded | Phase 3 |
| CC-06 | Does Claude Code's `PreToolUse` hook support our gate? | Hook in user-level settings that calls `mpx hook`; test allow, deny with reason, ask, `updatedInput`; measure round trip; confirm `onFailure: block` blocks on timeout and on daemon down; edit project settings mid-session to try to remove or disable the user-level hook | Decisions honoured; a 30-second biometric wait works; failures block; project settings cannot disable the user-level hook (or we document how we prevent it) | Phase 3 |
| CC-07 | Will agents call our MCP tools reliably? | Register `mpx mcp` with Claude Code; instruct it to call `report_progress` and `note_to_user`; run 10 varied tasks | Tool called at the end of most turns; fallback works when it is not | Phase 4 |
| CC-08 | What happens when we type into Claude Code while it is working? | Type a message mid-turn; type `/btw <question>` mid-turn; send Esc then a message | Behaviour documented: queued vs immediate, `/btw` answer shown without affecting history | Phase 4 |
| CC-09 | Which prefix key is free? | List the keybindings of Claude Code, opencode and Codex; test candidates in each terminal | One default prefix that no supported agent uses and every target terminal delivers | Phase 1 |
| CC-10 | Does conflict prediction work with the Git on the author's machine? | `git merge-tree --write-tree` on branches with and without conflicts | Conflicting files listed correctly, no worktree changes; Git version recorded | Phase 5 |
| CC-11 | Can we restrict agent writes to the worktree on Windows? | Try three routes: (a) Claude Code with its sandbox inside WSL2, launched from Windows through ConPTY, worktree on the WSL filesystem; (b) a child process at low integrity level with the worktree labelled writable; (c) an AppContainer. In each, run `pnpm install`, `go build`, `git commit`, and attempt writes outside the worktree | Writes outside the worktree fail; normal dev tools still work; record speed and workflow costs of each route | Phase 3 (OS layer) |
| CC-12 | How much does PowerShell startup cost per command? | Time `pwsh -NoProfile -Command exit` vs with profile vs a persistent session running 100 commands | Numbers recorded; agent shell default chosen | Phase 1 |
| CC-13 | How much does a Dev Drive help? | `pnpm install` and `go build` in a worktree on a normal NTFS folder vs a Dev Drive | Numbers recorded; recommendation written | Phase 2 |
| CC-14 | Does the push broker stop direct pushes from a worktree? | Set a per-worktree `pushurl`; try `git push` from the worktree; push through `mpx push` | Direct push fails; brokered push works after approval; agent cannot change the setting from inside the worktree | Phase 3 |
| CC-15 | Can routing Claude Code's shell commands through a daemon-owned persistent shell (via `updatedInput`) cut per-command overhead without changing results? | Rewrite Bash/PowerShell tool input to `mpx exec`; run a fixed task suite both ways; compare outputs, exit codes and timings | Same results, measurably lower overhead; otherwise drop the idea | Phase 7 or earlier if cheap |
